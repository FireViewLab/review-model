# 리뷰 라벨링 가이드 (요약)

v4.0 텍스트 모델의 학습·평가 데이터에 쓴 라벨 기준이다.

## 원칙

- 라벨은 "가짜 리뷰라는 판결"이 아니다. 주어진 정보로 위험 근거를 확인할 수 있는지를 판단한다.
- 후보 추출 사유나 모델 점수를 보지 않고 판정한다.
- 근거가 부족하다는 사실을 정상의 증거로도, 의심의 증거로도 쓰지 않는다.
- 사진이 있다고 정상으로 보지 않는다. 사진이 없다고 의심하지 않는다.

## 라벨

| 라벨 | 기준 | 학습 |
|---|---|---|
| `NORMAL` | 정의된 의심 신호가 명확하게 없다 | 0 |
| `SUSPICIOUS` | 텍스트·작성 행동·리뷰 간 관계에서 구체적 위험 근거가 있다 | 1 |
| `DISCLOSED_PROMO` | 체험단·협찬·광고·제품 제공·리뷰 이벤트 참여를 밝혔다 | 제외 |
| `UNCERTAIN` | 정보가 부족하거나 근거가 상충한다 | 제외 |
| `INVALID` | 리뷰 본문이 아니다 | 제외 |

## 판정 규칙

1. 광고나 제공 사실을 밝혔으면 의심 신호가 함께 있어도 `DISCLOSED_PROMO`다. 의심 신호는 신호 코드에 같이 적는다.
2. 보상을 받고 쓴 사실(리뷰 이벤트 등)을 밝혔으면 `DISCLOSED_PROMO`다.
3. 짧은 만족 표현만 있고 다른 신호가 없으면 `NORMAL`이다.
4. 칭찬이나 홍보 문구만으로는 `SUSPICIOUS`가 아니다. 판매 유도가 본문 대부분을 차지하고 사용 경험이 없을 때만 근거가 된다.
5. 신호 하나로 판정할 때는 근거와 반대 가능성을 메모에 남긴다.
6. 행동·관계 신호 하나만 있고 본문이 평범한 사용 후기면 `UNCERTAIN`을 먼저 검토한다.

## 신호 코드

정의는 `src/review_model/constants.py`의 `SIGNALS`에 있다. 텍스트 신호는 설명문, 미사용 단정, 판매 유도, 과도한 확신, 반복이다. 행동·관계 신호는 하루·한 시간 몰림, 별점 분포 편차, 상품 간·상품 내 동일 문장, 작성자 반복이다. 광고 표시는 따로 기록한다.

## 정보 해석

- 사진 정보가 없는 것("미확인")은 사진 0장과 다르다.
- 별점이 없으면 5점으로 가정하지 않는다. 5점 자체는 신호가 아니다.
- 동일 문장 수에는 짧은 상투 문구가 섞여 있다. 같은 리뷰가 여러 옵션 상품에 공유된 경우는 제외한다. 숫자만으로 판정하지 않는다.
- 몰림은 그 상품의 평소 대비로 본다.

## 절차

1. 신호 기반 후보와 무작위 대조군을 함께 뽑는다(`candidates.flags`).
2. 검수자에게는 원문과 관련 데이터만 보여준다. 후보 사유는 키 파일에만 둔다(`packet.build`).
3. 판정할 때 라벨, 광고 표시, 신호 코드, 근거 메모를 남긴다.
4. 두 번째 판정과 의심 여부가 갈리면 `UNCERTAIN`으로 돌린다(`labeling.consensus`).
5. 일치도를 기록한다(`labeling.agreement`).

## 학습 반영

- `NORMAL`과 `SUSPICIOUS`만 학습한다.
- 같은 리뷰는 한 번만 센다.
- 같은 상품, 같은 본문, 같은 작성자로 이어진 리뷰는 같은 split에 넣는다(`dataset.split`).
- 합성 데이터는 학습에만, 20% 이하로 쓴다.

## 한계

- 본문 중심 기준이라, 평범하게 잘 쓴 조작 리뷰는 정답에서도 빠질 수 있다.
- v4.0 라벨은 사람 2인 독립 검수가 아니다. 모델 판정과 교차 확인으로 만들었고, 사람 확인 소량 시험 세트로 보완한다.
